# TRAVEL_APP — Phiên Bản Mobile React Native (Expo)

> **Mục đích**: Đây là bản chuẩn bị sẵn sàng (song hành / dự phòng) dựa trên nền tảng React Native (Expo).

## Hướng dẫn chạy thử nghiệm
1. Cài đặt dependencies:
   ```bash
   npm install
   ```
2. Chạy ứng dụng:
   ```bash
   npx expo start
   ```
3. Mở ứng dụng **Expo Go** trên điện thoại thật (iOS/Android), quét mã QR trên terminal để trải nghiệm ứng dụng ngay tức thì.
